- (insight by coach) Converged on 5 finalists for a 5hr beginner Claude Code build: (1) Brain-Dump Triage ('inbox zero for your brain') - paste messy thoughts, LLM sorts into Do Today/Schedule/Delegate/Delete; (2) Interactive Plain-English Doc Explainer - paste a bill/contract/letter, click any sentence for plain-English + risk/action explanation; (3) Pre-Send Regret Checker - paste a draft message/email, get tone flags + 'will future-you regret this' + rewrite suggestion; (4) Commitment Extractor - paste chat/email threads, surface implicit promises and deadlines you made that you'd otherwise forget; (5) Devil's-Advocate Decision Cooling-Off - describe a decision you're leaning toward, tool argues the strongest opposing case plus a cooling-off timer before you act. All five share the same lean build shape: single static HTML/JS page, no backend/auth/database, call an LLM API (or route through Claude) for the 'smart' step, paste-in text instead of live integrations -- keeping scope realistic for 5 hours as a beginner while still feeling clever/exciting via the interactive demo moment (highlighting text live, watching the devil's advocate argue back, seeing triage happen instantly).
- (decision by user) Chosen direction: T&Cs/Terms-of-Service checker - paste/upload a product's T&Cs, tool scans and flags unusual or intrusive terms, categorized by severity, shown in a visually appealing simple UI. Builds on finalist #2 (Interactive Plain-English Doc Explainer), sharpened into a specific severity-flagging product.
- (decision by coach) Locked v1 scope for the T&Cs checker ('ClauseGuard' working name): (1) Input = paste raw T&Cs text (URL-fetch is a stretch goal only, skipped for v1 to avoid CORS/scraping risk in a beginner 5hr build); (2) Severity taxonomy = 3 fixed tiers - Critical (e.g. data selling, forced arbitration, auto-renewal traps, liability waivers), Caution (e.g. broad data collection, vague cancellation terms), Standard (normal/expected terms); (3) Output = for each flagged clause show the quoted text, a plain-English explanation of why it matters, and a severity badge, grouped/sorted by severity; (4) Architecture = single static HTML/JS page, no backend/auth/database, one LLM API call does the extraction+classification, keeping the whole build realistic for a beginner in 5 hours while the live 'paste it and watch it get flagged' moment carries the demo.
- (insight by coach) Final synthesis: the chosen idea is finalist #2 (Interactive Plain-English Doc Explainer) sharpened by the user into a specific product - a T&Cs severity checker. It inherits the 'click to explain inline' demo-ability praised in the SCAMPER-Modify pass, the 'single best feature, nothing else' discipline from Ship-in-60-Minutes/Eliminate, and the paste-in-text, LLM-does-the-work architecture validated across the whole session as the only realistic path to a working beginner build in 5 hours. The severity-categorized UI is what elevates it from 'summarizer' to genuinely clever/innovative - it turns an unreadable wall of legal text into a ranked, scannable risk map in seconds, which is also what makes it an exciting live demo.
